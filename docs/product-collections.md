# Тематические подборки (`ProductCollection`)

Руководство для наполнения подборок в админке и подготовки посадочных страниц под Яндекс Директ.

**Админка:** Товары → Тематические подборки (`/admin/products/productcollection/`)  
**Публичные URL:** `/collections/` (индекс), `/collections/<slug>/` (лендинг)  
**Feature flag:** `COLLECTIONS_ENABLED=True` в `.env` / `deploy/.env` (на prod по умолчанию `False`)

Подробный маркетинговый план: [.cursor/plans/collections-yandex-direct-2026.md](../.cursor/plans/collections-yandex-direct-2026.md).

---

## Зачем нужны подборки

Подборка — **отдельная посадочная страница** с фиксированным списком товаров. Её URL вставляют в объявления Директа. Это не то же самое, что **категория каталога** (`/catalog/?category=...`): категории — постоянная навигация сайта, подборки — рекламные и сезонные витрины.

Сейчас подборки **не выводятся в header и footer** (только прямой URL + sitemap). Блоки на главной и в каталоге — запланированы, но ещё не реализованы (см. флаги ниже).

---

## Пошагово: как добавить подборку

### 1. Создать черновик

1. Админка → **Тематические подборки** → **Добавить**.
2. Заполнить обязательные поля (см. таблицу ниже).
3. **Сохранить** (можно без галочки «Опубликовано»).

### 2. Добавить товары (inline внизу формы)

| Поле inline | Зачем |
|---|---|
| **Продукт** | Товар из каталога. Должен иметь **активный файл** (`ProductFile`, `is_active=True`), иначе на витрине не покажется. |
| **Порядок** | Порядок на странице (меньше — выше). По умолчанию сортировка на сайте совпадает с этим полем. |
| **Выделить** | *Зарезервировано.* Пока не влияет на вёрстку. |
| **Метка** | *Зарезервировано.* Короткая подпись на карточке (например «Хит») — в MVP не выводится. |

Дубликаты одного товара в одной подборке запрещены.

### 3. Проверить готовность

В блоке **Публикация** смотрите поле **«Готовность к публикации»**:

- зелёное — достаточно видимых товаров и даты в окне публикации;
- жёлтое — «Видимых товаров: N из M» (обычно M = 5).

**Видимый товар** = добавлен в подборку **и** имеет активный файл для скачивания.

### 4. Опубликовать

Включите **«Опубликовано»** и сохраните. Если товаров меньше минимума или даты вне окна — сохранение не пройдёт валидацию.

### 5. Проверить на сайте

- Индекс: `/collections/` — карточка подборки в сетке.
- Лендинг: `/collections/<slug>/` — список товаров, сортировка, пагинация.
- В админке в блоке **Публикация** — **Публичный URL** (`/collections/markirovka-ds/` и т.п.).

## Поля подборки

### Основное

| Поле | Обязательно | Где используется | Рекомендации |
|---|---|---|---|
| **Название** | да | H1 на лендинге, карточка на `/collections/` | Коротко, по intent запроса: «Маркировка для детского сада». |
| **Слаг** | да | URL `/collections/<slug>/` | Латиница, без пробелов. **Для кириллических названий slug задайте вручную** — автогенерация из title не транслитерирует. Уникален среди подборок, категорий и товаров. |
| **Краткое описание** | нет | Под H1 на лендинге, текст на карточке индекса | 1–2 предложения, до 240 символов. |
| **Описание** | нет | SEO-блок внизу лендинга | Развёрнутый текст для пользователя и SEO (можно с переносами строк). |

### SEO

| Поле | Обязательно | Где используется | Рекомендации |
|---|---|---|---|
| **SEO title** | нет | `<title>`, Open Graph | Если пусто — `{Название} — PalinGames`. До ~70 символов. |
| **SEO description** | нет | meta description, OG | Если пусто — берётся краткое или полное описание. До ~160 символов. |
| **Robots** | да (default) | meta robots | Для рекламных лендингов: **`index,follow`**. Вариант `noindex,follow` — для тестов или временных страниц. Страницы с `?sort=` и `?page=` всегда `noindex`. |
| **Код кампании (UTM)** | нет | *Пока только справочно в админке* | Внутний ярлык кампании Директа (например `markirovka_ds_2026`). UTM в объявлениях настраиваются в Директе вручную; поле помогает не путать подборки в отчётах. |

### Обложка

| Поле | Обязательно | Где используется | Рекомендации |
|---|---|---|---|
| **Обложка** | нет | Карточка на `/collections/` | JPG/PNG. Хранится в S3: `collections/{slug}/{uuid}.ext`. Если пусто — logo.svg. |

**Локальная разработка:** MinIO должен отдавать prefix `collections/*` публично (`make up-develop` → `minio-init`).  
**Production:** в bucket policy public read на `previews/*` и `collections/*` (см. [deploy/README.md](../deploy/README.md)).

### Публикация

| Поле | Обязательно | Значение по умолчанию | Зачем |
|---|---|---|---|
| **Опубликовано** | — | выкл. | Главный переключатель. Без него страница 404. |
| **Минимум товаров для публикации** | да | **5** | Нельзя опубликовать, пока видимых товаров меньше этого числа. |
| **Публикация с** | нет | пусто | Подборка скрыта до этой даты (часовой пояс Django). Для сезонных: например `2026-09-01`. |
| **Публикация до** | нет | пусто | После этой даты подборка снимается с витрины и sitemap. |

### Навигация и оформление

| Поле | MVP | Зачем |
|---|---|---|
| **Порядок** | **да** | Сортировка карточек на `/collections/` (меньше — раньше). |
| **Бейдж** | **да** | Короткая метка на **карточке в индексе** (до 32 символов): «Сезон», «Новинка», «−20%». Не обязательное; пустое — бейдж не рисуется. |
| **Показывать на главной** | *нет* | Зарезервировано: блок избранных подборок на главной (S2-10). **Сейчас не влияет на сайт.** |
| **Показывать в каталоге** | *нет* | Зарезервировано: блок «Тематические подборки» на `/catalog/` (S2-09). **Сейчас не влияет.** |
| **Показывать в навигации** | *нет* | Зарезервировано: пункт меню / burger. **Сейчас не влияет.** |
| **Показывать в футере** | *нет* | Решение PO: **явной ссылки в footer нет** (рекламные лендинги). Поле на будущее; **сейчас не влияет.** |

**Итого по булевым полям:** в MVP реально работают только **«Опубликовано»** и косвенно окно дат. Остальные четыре `show_*` — заготовка под следующие спринты; их можно не трогать (оставить выключенными).

## Что видит пользователь на сайте

| Страница | Содержимое |
|---|---|
| `/collections/` | Сетка карточек: обложка, название, бейдж (если есть), краткое описание. |
| `/collections/<slug>/` | H1, краткое описание, сортировка, сетка товаров (те же карточки, что в каталоге), описание внизу. |
| Header / footer | Ссылок на подборки **нет** (намеренно). |
| Sitemap | `/collections/` и URL опубликованных подборок (при `COLLECTIONS_ENABLED=True`). |

## Чеклист перед запуском рекламы

- [ ] `COLLECTIONS_ENABLED=True` на staging/prod
- [ ] Slug латиницей, URL открывается без авторизации
- [ ] ≥ 5 товаров с активными файлами
- [ ] SEO title/description заполнены под ключевые запросы
- [ ] Robots = `index,follow` для рекламной подборки
- [ ] Обложка загружена и открывается по URL (проверить в браузере)
- [ ] UTM прописаны в кампании Директа (не в Django)
- [ ] GTM: `page_type=collection`, `view_item_list` с `item_list_id` = slug

## Типичные ошибки

| Симптом | Причина | Решение |
|---|---|---|
| 404 на `/collections/` | `COLLECTIONS_ENABLED=False` | Включить flag, перезапустить Django |
| 404 на лендинге | Не опубликовано, мало товаров или вне дат | Проверить «Готовность к публикации» |
| Товар в админке есть, на сайте нет | Нет активного `ProductFile` | Загрузить файл товара, `is_active=True` |
| Обложка не грузится | MinIO/S3 без public read на `collections/*` | Локально: `docker compose -f docker-compose.develop.yml run --rm minio-init`; prod: bucket policy |
| Не сохраняется «Опубликовано» | Меньше 5 видимых товаров | Добавить товары или временно снизить минимум (не рекомендуется для prod) |
| Slug конфликтует | Совпадает с категорией или товаром | Выбрать другой slug |
